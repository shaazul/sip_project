Unity Description

We provide a fully interactive 3D building visualization platform powered by Unity,

designed to transform how building owners and facility managers monitor, understand,

and operate their Building Management System (BMS).

Our solution combines real-time system data, 3D building models, and 2D schematic views

into one intuitive interface giving users complete visibility of the building, from overall

structure down to individual equipment.

Full Building Visualization

The system presents the entire building in high-fidelity 3D, allowing users to:

• View the whole building structure

• Navigate floor by floor

• Zoom into specific rooms, zones, or plant areas

• Instantly identify where each system and asset is located

Interactive Floor & Level Navigation

At the bottom of the interface, users can select any building level:

• Clicking a level automatically brings the user to the selected floor

• The system highlights all mapped BMS assets on that floor

• Equipment locations are clearly shown based on actual room and area placement
