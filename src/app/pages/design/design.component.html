System Navigation & Power Overview

Left Panel - System Navigation

The System Navigation panel provides direct access to all major building systems in one place. When a user selects a system from the left panel:

• The interface automatically navigates to the relevant Unified Control data table

• Live system information is displayed clearly in a structured format

• Users can immediately review status, performance and operational data

Right Panel - Power & Energy Summary Dashboard

The Power Summary panel provides a high-level overview of the building's energy performance in real time. It displays key indicators such as:

• Overall and average energy consumption

• Power demand and usage trends

• Solar generation performance

• Battery status and energy storage levels

• Solar panel contribution to total energy usage

Smart Floor-Level Navigation & System Mapping

Direct Floor Selection (Step-Based Navigation)

At Step 2, users can select any floor directly from the floor navigation interface. When a floor is selected:

• The view automatically transitions to the chosen floor

• Live system information is displayed clearly in a structured format

Complete System Mapping by Floor

Once select the floor, the system displays the exact location of building services. Each system is mapped based on its actual room and zone location.

Continuous Level Navigation via Scroll Control

To direct floor selection, users can still navigate smoothly between levels using the scroll level function located at the bottom of the interface.

System Monitoring & Detailed Status

Asset-Level View

When a user clicks on an system services displayed on the selected floor map:

• The system automatically navigates to the system detail page

• The selected system is shown in a dedicated 3D and 2D view

• All related operational data is presented in a clear & structured layout

Real-Time System Status & Operational Data

Each system detail page provides comprehensive system information, including:

• Operational status (running, standby, fault, etc.)

• Supply and return air parameters

• Temperature, pressure, and airflow readings

• Filter condition and system alarms (if applicable)
